# Returning an unwanted item within the return window

This policy covers customers who no longer want an item that was delivered in
resalable condition. It does not govern physical damage, failed delivery, or a
request to cancel an order that has not shipped. Damage claims follow
`refund_damaged_item` even when the delivery occurred fewer than 30 days ago.

A verified customer may initiate a return for an undamaged, unused, or
otherwise resalable item within 30 calendar days of recorded delivery. The
request must be made within the window. Initiating a return establishes a
return case but does not by itself establish refund eligibility.

The full return percentage in `refund_calculation` becomes available only
after the customer confirms that the item has been shipped back. A statement
that the customer intends to ship it, has packed it, or will visit a carrier
later is not confirmation that it has been shipped. The automated agent must
not issue the return refund while shipment remains prospective.

An undamaged item outside the 30-day window is not refundable under this
policy. A customer with more than 12 months of account history may receive a
$5 goodwill store credit, but only when the operational tools support such a
credit and the case is not actually a damage claim. If the available write
tools cannot issue that specific credit, escalate rather than describing it as
completed.

If the customer says they attempted to initiate the return within the window
but the recorded request is late, escalate at priority `normal` for review.
The escalation is not a return approval. Any eventual refund remains subject
to prior-refund subtraction and `refund_authority`.
